# BASS-for-Unity
BASS Audio Library for Unity wrapper

BASS version: 2.4.18.3

Download bass24.zip from the official un4seen.com website (Win32: https://www.un4seen.com/files/bass24.zip).

Unpack bass24.zip.Inside Assets, create a folder named Plugins. 

Inside the Plugins folder, create a folder named BASS. 

Inside the BASS folder, create folders named x86 and x86_64.

Open the unpacked bass24 folder, take bass.dll from there, and paste it into the created x86 folder.

Open the unpacked bass24 folder, go to the x64 folder, take bass.dll from there, and paste it into the created x86_64 folder.
